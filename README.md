# Cidade Grau - Brasil | V0.1

Protótipo inicial em Godot 4 para Android. O projeto cria uma pequena rua de teste, casas simples, uma moto estilizada e controles de toque.

## Abrir pelo celular
1. Baixe o Godot Editor para Android pelo site oficial: https://godotengine.org/download/android/
2. Extraia este ZIP em uma pasta do aparelho.
3. Abra o projeto `project.godot` no Godot Editor.
4. Execute a cena principal para testar.

## Controles
- ACELERAR: acelera a moto.
- FREIO: reduz a velocidade.
- ◀ / ▶: direção.
- GRAU: aplica torque para levantar a frente.

## Importante
Esta é uma base técnica V0.1, não um jogo final nem uma reprodução do Projeto Grau 2. A moto ainda usa uma física simplificada: suspensão independente, rodas com juntas, câmbio, sons, animações, mapa detalhado e otimização mobile serão etapas seguintes.
